# CodaBridge

Listen to real sperm-whale recordings, compare their timing patterns, and investigate the evidence with GPT-6 Astra.

**Status: development kickoff. No application, live model integration, or hosted deployment is available yet.**

## Product direction

Build a small, English-first public web app in which a visitor can listen, compare absolute and normalized click timing, ask a grounded question, and inspect the measurements and sources behind the answer. This is an exploration tool, not a claimed whale-to-human translator.

The release target is the September 18, 2026 GPT-6 Astra Challenge on Product Hunt. Start with a few carefully attributed recordings and a complete interaction rather than a large catalog or an unvalidated research claim.

## Development

The current scope and delivery plan are tracked in [issue #1](https://github.com/hynk-studio/CodaBridge/issues/1).

- ChatGPT plans and reviews; Codex implements, tests, and submits changes through pull requests.
- GitHub is the source of truth. ChatGPT Sites is the proposed publishing target, subject to compatibility checks and a later explicit deployment decision.
- This initial README is the one-time empty-repository bootstrap. Product implementation belongs on a branch and in a reviewable PR.
- Keep the project independent of Augnes and unrelated repositories or deployed Sites.

## Data and attribution

Only include material whose reuse conditions have been checked. Retain source IDs, attribution, license references, transformations, and the origin of click annotations. Separate measurements from generated interpretation and real recordings from synthetic examples.

Project code licensing has not yet been selected; third-party data and dependencies retain their own licenses. Public visibility is not a substitute for a license.
